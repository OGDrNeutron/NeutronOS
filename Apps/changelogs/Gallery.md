# Gallery

## 1.0.0-alpha.2

### Current Release

- Controller-first photo and video library built for NeutronOS.
- Browse photos, screenshots, videos and screen recordings from one unified library.
- Organize media through albums and library filters.
- Mark media as favorites for quick access.
- View detailed file and media metadata.
- Full-screen photo viewing with zoom and panning controls.
- Built-in slideshow viewing.
- Integrated video playback.
- Cached video thumbnails for faster library browsing.
- File management controls directly from Gallery.
- Background library scanning keeps media collections current.
- Dedicated handling for screenshots and screen recordings.
- Modular Gallery interface optimized for controller navigation.
- FFmpeg and ffprobe integration for video metadata and thumbnail generation.
- Corrected App Store dependency handling so OS-provided FFmpeg is not unnecessarily reinstalled.
- Qt Multimedia is installed only when the required playback module is actually missing.
- Distributed as an officially signed NeutronOS App Store package.
