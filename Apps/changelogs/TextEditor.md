# Text Editor

## 1.1.1

### Current Release

- Controller-first text and source editor built for NeutronOS.
- Create and edit text, configuration and source-code files.
- Open existing files or start with untitled documents.
- Syntax highlighting for supported file and language types.
- Integrated line numbers for easier source navigation.
- Built-in structural syntax diagnostics.
- Optional Python syntax diagnostics when Python is available.
- Find and replace tools for navigating and editing larger documents.
- Undo and redo support throughout editing sessions.
- Preview autocorrect suggestions before applying changes.
- Atomic save handling helps protect files from partial writes.
- Automatic recovery support for interrupted editing sessions.
- Preserves recovery files and backups across uninstall and reinstall.
- Maintains recent-file history for quick access to active work.
- Preserves user documents outside App Store package ownership.
- Developer Mode safeguards protect sensitive NeutronOS system files.
- Uses OS-owned TextEditorManager and Developer Mode integration.
- Requires no additional Debian packages from the App Store.
- Distributed as an officially signed NeutronOS App Store package.
