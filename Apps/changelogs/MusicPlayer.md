# Music Player

## 1.0.1

### Current Release

- Controller-first music player built for NeutronOS.
- Scan and cache local music libraries for fast browsing.
- Browse music by tracks, albums, artists and folders.
- Create and manage playlists.
- Build and manage the active playback queue.
- Integrated playback controls optimized for controller navigation.
- Select app-specific audio outputs.
- Supports background music playback.
- Displays and manages album and track artwork.
- Preserves downloaded and extracted artwork in the local artwork cache.
- Inspect embedded media metadata.
- Preview filename and metadata corrections before applying them.
- Batch repair filenames across multiple tracks.
- Batch repair embedded music metadata.
- Uses FFmpeg and ffprobe for media inspection and metadata operations.
- Uses mpv as the playback engine.
- Preserves library cache, playlists, artwork and settings across uninstall and reinstall.
- Keeps MusicPlayerManager integrated as OS-owned support.
- Distributed as an officially signed NeutronOS App Store package.
