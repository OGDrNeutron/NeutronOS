# Browser

## 1.2.0

### Current Release

- Controller-first fullscreen web browsing built specifically for NeutronOS.
- Multi-tab browsing with standard and private tabs.
- Integrated bookmarks, browsing history and download management.
- Controller-friendly URL and search navigation.
- Persistent browser state across updates and reinstalls.
- Built-in media controls for web playback.
- Performance and DRM controls for compatible web content.
- Advanced browser and media diagnostics.
- Extension management interface.
- Browser capture and recording controls.
- Native HTML, CSS and JavaScript web support.
- Sandboxed Python-enabled web content.
- Modular browser interface with dedicated tabs, library, media, diagnostics and settings panels.
- Distributed as an officially signed NeutronOS App Store package.
- Automatically verifies the required Qt WebEngine runtime before installation.
