# Games

## 1.1.1

### Current Release

- Controller-first game library built for NeutronOS.
- Automatically discovers supported ROMs and Flash games.
- Browse and launch games from a unified visual library.
- Manage custom artwork and game cards.
- Configure per-game settings.
- Reorder the game library to match your preferred layout.
- Launch controller-ready emulator sessions through NeutronOS display handoff.
- Supports RetroArch and compatible Libretro cores.
- Supports Mupen64Plus for Nintendo 64 titles.
- Supports Dolphin for compatible GameCube and Wii titles.
- Supports PPSSPP for PSP games.
- Supports Ruffle for compatible Flash games.
- Supports Moonlight and compatible cloud/streaming game services.
- Emulator and cloud runtimes are installed only when the user chooses to use them.
- Preserves user ROMs and artwork outside package ownership.
- Keeps GamesManager and display-handoff support integrated with NeutronOS.
- Distributed as an officially signed NeutronOS App Store package.
