# qBittorrent

## 1.0.1

### Current Release

- Controller-first qBittorrent management interface built for NeutronOS.
- Browse and manage torrents from a unified NeutronOS interface.
- View active torrent status and transfer information.
- Inspect torrent files and download activity.
- Add torrents from local torrent files.
- Remove torrents directly from the library.
- Integrated controls for everyday torrent and download management.
- Connect to a local qBittorrent Web API.
- Connect to compatible remote qBittorrent Web API servers.
- Built-in connection and setup controls.
- Preserves qBittorrent API settings and credentials across uninstall and reinstall.
- Can reuse an existing native qBittorrent service.
- Can reuse an existing Docker-based qBittorrent installation.
- Does not force qBittorrent-nox installation when another backend already exists.
- Does not force Docker installation when it is not needed.
- Keeps QBitTorrentManager integrated as OS-owned support.
- Requires no additional Debian packages from the App Store.
- Distributed as an officially signed NeutronOS App Store package.
