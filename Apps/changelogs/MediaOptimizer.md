# Media Optimizer

## 2.0.1

### Current Release

- Controller-first media compatibility and optimization tool built for NeutronOS.
- Scan media libraries and analyze files for playback compatibility.
- Identify media that can benefit from optimization.
- Sort and prioritize files by optimization need.
- Inspect video, audio and subtitle stream information.
- Manage audio tracks and subtitle tracks before optimization.
- Estimate storage savings before processing media.
- Run guarded FFmpeg optimization workflows directly from NeutronOS.
- Includes additional safeguards for potentially destructive or high-impact conversions.
- Displays active optimization progress and operation status.
- Preserves optimization settings and reusable presets.
- Preserves media scan cache across uninstall and reinstall.
- Uses NeutronOS-provided FFmpeg and ffprobe tools without reinstalling them.
- Keeps MediaOptimizerManager integrated as OS-owned support.
- Requires no additional Debian packages from the App Store.
- Distributed as an officially signed NeutronOS App Store package.
