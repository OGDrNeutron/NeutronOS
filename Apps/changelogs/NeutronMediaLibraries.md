# Neutron Media Libraries

## 1.1.1

### Current Release

- Controller-first personal media library built for NeutronOS and powered by Jellyfin.
- Browse movies, TV shows, music, collections and playlists from one unified interface.
- Dedicated TV navigation follows Library → Series → Season → Episode.
- Automatically creates season folders when a Jellyfin server does not expose them directly.
- Correctly organizes episodes using series and season information from Jellyfin.
- Centered media-card layouts across movies, TV, collections, playlists and music.
- Rich poster and backdrop artwork throughout the media library.
- Uses Jellyfin server splash and backdrop artwork as the default logged-in background when available.
- Server artwork can be enabled or disabled from Colors & Theme.
- Dedicated Home, Settings and Customize navigation.
- Controller-first browsing and playback controls throughout the interface.
- Supports local playback directly on NeutronOS.
- Supports Roku playback integration.
- Supports direct LAN playback for compatible devices.
- Designed for both normal networks and offline/local-only Wi-Fi environments.
- Integrated Jellyfin server connection and setup handling.
- Can work with an existing Jellyfin backend or provision one when required.
- Standardized NeutronOS exit dialog and controller behavior.
- Preserves media-library state and configuration across package updates.
- Distributed as an officially signed NeutronOS App Store package.
