# Games — Gemini 0.1.0-review.2

Requires Gemini 0.5.5, AMD64, Qt 6.8.2, and shared package-session/controller-proxy/geometry API v1.

Games now includes its own precompiled native backend and local QML/resources. Installation no longer rebuilds NeutronOS or NeutronShell. Signed manifests declare native file hashes and exact platform/capability requirements. Existing game-library, artwork, controller navigation and supervised game-session behavior are retained.

The earlier review.1 package remains available in repository history. This remains an engineering review package; physical gameplay and RX 470 behavior require real-hardware confirmation.
