IMPORTANT LEGACY-ADOPTION SAFETY:
The current NeutronOS package helper treats qml/apps/games as a single legacy
source directory during first App Store adoption. That directory currently also
contains user ROMs and card artwork. Games 1.1.1 intentionally does NOT package
or publish those files. Do not perform first-time Games App Store adoption until
the OS-owned package helper is updated to preserve games/roms and games/cards.
Publishing this release to Git is safe; first-time installation on a legacy
source-tree Games installation is the operation that needs the OS-side fix.
